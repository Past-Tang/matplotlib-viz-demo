## 概述

基于 Matplotlib 的数据可视化案例集合，包含多种常见图表类型的绘制示例，适合数据分析入门学习。支持从 Excel 文件读取数据并生成专业图表。

## 包含案例

- 折线图、柱状图、饼图等基础图表
- 多子图组合布局
- Excel 数据读取与可视化
- 图表样式自定义

## 技术栈

- **绘图**: Matplotlib
- **数据处理**: Pandas, openpyxl
- **数据源**: Excel (.xlsx)
